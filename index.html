Разметка
Семантический HTML, ни одного дива ради дива. Открывается без JS почти целиком.
Стили
Дизайн-токены в CSS-переменных, сетки на Grid, острые углы и жёсткие тени — брутализм, но тёплый.
Логика
Ванильный JS: печать в терминале, scramble-заголовки, счётчики, стена записок. Никаких библиотек.
Хранилище
Записки и настройки — в localStorage посетителя. Сервер не нужен, приватность по умолчанию.
Деплой
GitHub Pages / Netlify Drop: перетащил файл — сайт в интернете.
