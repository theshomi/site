# theshomi

Dark luxury personal wall. Style: Janice STFU / Iceman.

## Quick start

```bash
npm install
npm run dev
```

## Deploy to GitHub Pages

1. Create repo `theshomi.github.io` (or any name)
2. Push this project
3. In repo Settings → Pages → Source: **GitHub Actions**
4. Put your avatar as `public/avatar.jpg`
5. Edit links and projects in `src/pages/index.astro`

After first push the site will be live at `https://username.github.io` (or `/repo-name`).

## Style notes

- Pure black background
- Cold champagne / muted gold accents
- Minimal, no pathos
- High contrast portrait
